每个管理员仅拥有一个角色，在创建或修改时选择即可。系统预置 admin 不可删除、不可降级、不可禁用。

角色权限管理

本页只负责定义角色和权限。给管理员指定角色请到「管理员管理」——创建或修改账号时选一个角色即可（每人仅一个角色）。

  1. 下方可查看全部角色；系统内置角色（超级管理员、内容审核员、数据管理员）不可删除。

  3. 已有角色需要调整时，在「调整已有角色权限」里选择角色并修改勾选。
